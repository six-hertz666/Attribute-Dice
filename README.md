# 属性骰子

> 本模组使用 AI 辅助制作

这是一个 Minecraft Java 1.21.11 Fabric 模组，添加了六种各具特色的骰子物品：属性骰子、霉运骰子、财富骰子、伤害骰子、护甲骰子和生命骰子。

> 提示：赌大伤身，请不要过度使用！

## 物品一览

### 1. 属性骰子

使用稀有材料合成的骰子，投出高点数获得属性增强，投出低点数则属性受损。

- **合成配方**（3x3）：四角为金锭，中心为远古残骸，其余四个格子为钻石。
- **右键点击**骰子物品在你面前投掷一个旋转的骰子实体。约3秒后停止并显示投出的点数。
- **Shift + 右键点击**实体瞄准其他生物，对其使用骰子。
- **4 / 5 / 6（高点）**：获得随机属性（攻击伤害 / 护甲 / 最大生命值）。
- **1 / 2 / 3（低点）**：失去随机属性（同上）。
- **投出1点**：额外造成闪电伤害（默认10）并召唤闪电击中玩家。
- 每个面（1–6）出现的概率相同。
- 聊天消息显示投出的点数：1/2/3 为红色，4/5/6 为绿色。

### 2. 霉运骰子

专为坑害其他实体设计的骰子，所有结果都是减少属性，效果可累积。

- **合成配方**（3x3）：上下左右为不祥之瓶，中心为属性骰子。
- **右键点击**瞄准其他实体（无需按住 Shift），对目标使用霉运骰子。
- **所有结果均为负面**：1~6 点全部造成属性减少。
- **效果累积**：每次使用的属性减少效果永久累积，不会替换旧效果。
- **不触发闪电**：即使投出 1 点也不会召唤闪电。
- **不能对自己使用**：如果没有瞄准其他有效实体，会提示错误且不消耗物品。

### 3. 财富骰子

只能对自己使用的幸运骰子，永远不会投出低点数，还能获得珍贵的结构战利品！

- **合成配方**（3x3）：8 颗绿宝石围绕中心的属性骰子。
- **右键点击**只对自己使用，无需瞄准其他实体。
- **只会投出 4 / 5 / 6 点**：永远不会出现 1 / 2 / 3 点。
- **所有结果均为正面**：增加随机属性（攻击伤害 / 护甲 / 最大生命值）。
- **额外战利品奖励**：
  - 投出 **4 点** → 获得**村庄铁匠铺**战利品（工具、装备等）。
  - 投出 **5 点** → 获得**沙漠神殿**战利品（稀有矿物、附魔书等）。
  - 投出 **6 点** → 获得**猪灵堡垒**战利品（下界合金碎片、珍贵物品等）。
- 战利品物品自动放入背包，若背包已满则掉落在玩家脚下。
- 聊天消息以金色显示财富骰子的投掷结果和战利品获取提示。

### 4. 伤害骰子

专门修改攻击伤害的骰子，所有点数都只影响攻击伤害属性。

- **合成配方**（3x3）：8 把铜剑围绕中心的属性骰子。
- 使用方式与属性骰子相同，但所有结果（增减）都只作用于**攻击伤害**。

### 5. 护甲骰子

专门修改护甲值的骰子，所有点数都只影响护甲属性。

- **合成配方**（3x3）：8 件铜胸甲围绕中心的属性骰子。
- 使用方式与属性骰子相同，但所有结果（增减）都只作用于**护甲值**。

### 6. 生命骰子

专门修改最大生命值的骰子，所有点数都只影响生命属性。

- **合成配方**（3x3）：8 颗恶魂之泪围绕中心的属性骰子。
- 使用方式与属性骰子相同，但所有结果（增减）都只作用于**最大生命值**。

## BOSS 掉落

击败强大的 BOSS 有机会获得属性骰子奖励！骰子会掉落在 BOSS 死亡的位置。

| BOSS | 掉落数量 |
|------|---------|
| 末影龙 | 2 ~ 6 个 |
| 凋灵 | 2 ~ 6 个 |
| 远古守卫者 | 0 ~ 3 个 |
| 监守者 | 5 ~ 10 个 |

## 配置

以上所有参数都可以通过 `config/attribute_dice.json` 配置（首次运行时自动创建）。可配置项包括：
- 各点数的属性增减数值（范围或固定值）
- 是否启用 1 点闪电效果及伤害值
- 骰子旋转停留时间（刻）
- 霉运骰子各点数的损失范围

## 构建

要求：**JDK 21** 和网络连接（Gradle 将下载 Minecraft 映射文件）。

```bat
gradlew.bat build
```

输出 jar：`build/libs/attribute-dice-1.0.1.jar` — 将其放入 Fabric 的 `mods/` 文件夹中，并与 Fabric API 一起使用。
